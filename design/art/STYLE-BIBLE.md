# 水墨風格聖經 — 江湖一生

> 給美術、文案、UI、出圖 AI 共用的硬約束。  
> 一句話：**一筆成江湖，留白即命運。**

---

## 1. 身份

這不是 Assassin’s Creed 寫實武俠，也不是炫光卡牌手游。  
玩家在翻一軸**宣紙手卷**：紙面、淡墨遠山、朱砂印、年譜批註。

| 是 | 不是 |
|----|------|
| 手卷、題簽、批註、印章 | 儀表板、HUD 血條彩虹 |
| 留白、霧遠、一筆成形 | 滿版插圖、浮誇特效 |
| 漢字直意（根骨／悟性） | 西方 RPG 圖示列、emoji 主圖 |
| 直角或 ≤2px 圓角 | 大圓角卡片堆疊 |
| 墨底紙字按鈕 | 膠囊 CTA、紫漸層按鈕 |

---

## 2. 色彩

### 主色

```
--paper:        #F3EBDC   /* 宣紙 */
--paper-aged:   #E6D9C4   /* 舊紙／卷邊 */
--paper-bright: #FAF6EE   /* 高光紙 */
--ink:          #1A1A1A   /* 正文 */
--ink-mid:      #4A4540   /* 次要 */
--ink-wash:     #8A8278   /* 旁白 */
--ink-faint:    rgba(26,26,26,0.14)
--cinnabar:     #A33A32   /* 印／命運 */
--cinnabar-soft:rgba(163,58,50,0.14)
--mist:         rgba(26,26,26,0.06)
```

### 允許點綴（極克制）

| 色 | 建議 Hex | 用途 |
|----|----------|------|
| 古銅金 | `#8A7355` | 匾額細線、稀有器物描邊（勿大面積） |
| 青玉 | `#3D5C4F` | 信物／玉佩一筆點睛 |
| 松煙青 | `#2A3530` | 夜雨遠山加深層 |

### 語義

- **墨** = 敘事、日常、歲月
- **淡墨** = 旁白、未選之路、回憶
- **朱砂** = 命運確認（出生、蓋印、死亡、重大結緣）
- **玉／金** = 物件靈氣，不搶正文

### 禁止色調

紫→靛漸層、霓虹青粉、高飽和血紅滿版、純黑 UI 暗黑模式預設皮、奶油底 + 陶土橘「AI 海報預設」。

---

## 3. 構圖與氛圍

- **紙面均光**：無戲劇側光、無強陰影
- **遠山在下**：底部 30–55% 淡墨山形；上方留白給文字
- **墨漬**：角落軟圓暈，opacity 極低
- **霧**：靠透明度與輕 blur，**禁止 glow**
- **首屏**：品牌「江湖一生」最大；一句副句；一個 CTA 組；山水滿底。不要 stats／行程／地址條

---

## 4. 字體與排版

| 層級 | 建議 | 特徵 |
|------|------|------|
| 品牌／題簽 | 馬善政、站酷小薇、或強個性毛筆感 | 字距加寬 |
| 正文 | Noto Serif TC / Songti | 行高 1.6–1.75 |
| 批註選項 | 同正文略小，左側豎筆觸 | 像書眉批語 |
| 年譜 | 更小、淡墨 | 時間軸感 |

對比：墨字於紙面 ≥ 4.5:1。觸控行高 ≥ 44px。

---

## 5. UI 形狀語言

- 邊框：1px 淡墨線
- 主按鈕：墨底 + 紙色字
- 次按鈕：空心墨線
- 選項：左側豎線筆觸，hover／focus 加深
- 分隔：淡墨橫線兩端漸隱
- 進度（氣血）：淡墨條，**不要**遊戲紅血條感

---

## 6. 動效

| 時刻 | 動效 |
|------|------|
| 入場 | 墨暈淡入（opacity + 輕 blur） |
| 抉擇確認 | 朱砂印 scale 0.85→1 |
| 翻年 | 紙面微上移淡出／淡入 |
| 禁止 | 彈跳、霓虹脈衝、彈窗甩入 |

---

## 7. 角色與場景（文字遊戲特化）

- MVP **可不畫立繪**：姓名、歲數、門派、印記象徵身份
- 「場景」= 事件標題 + 一兩句正文；背景永遠是紙與山
- 插圖若需要：橫幅水墨（約 900×260 或方印 160×160），留白給字，勿塞滿細節

---

## 8. 圖像母題（適合文字遊戲的符號）

優先用**可辨識的單一物象**，一圖一意：

遠山 · 孤舟 · 石橋 · 竹 · 松 · 劍匣 · 傘 · 酒旗 · 燈籠 · 玉佩 · 殘荷 · 雁陣 · 殘碑 · 朱砂方印 · 卷軸軸頭

人物若出現：剪影或背影，五官從簡，衣袂用數筆寫出。

---

## 9. 禁止事項（硬）

1. 儀表板式多欄屬性牆當首屏
2. 彩色彩虹進度條
3. Emoji 作為主要圖示（用漢字或 SVG 墨線）
4. 大圓角厚陰影卡片堆
5. 版權角色／門派／招式視覺仿製
6. 「通用 AI 奇幻」金屬盔甲 + 魔法粒子
