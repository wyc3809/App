# 系統總覽（文字版）

此檔方便在手機閱讀；細節數值以同目錄旁的 JSON 為準。

## 人生節奏

- 每月可在「修煉」做 **3 次** 行動，然後回鎮居「翻過一頁」。
- 每月鎮居會出現約 3 個際遇選項；結果以浮層顯示。
- 奇遇有倒數，觸發後可學秘傳武學。

## 天下四維

見遊戲內「江湖」頁：

- **秩序**：綱紀／治安
- **險惡**：刀兵風險
- **市面**：買賣景氣
- **傳聞**：流言熱度

數值每月會漂移；部分事件選項會直接改動（`type: "world"`）。

## 心性：俠、邪、狂、惡

人物頁可見。事件選擇會依文案與明示效果改變心性；心性會限制：

- 可拜入的門派（見 `sects/sects.json` 的 `natureGate`）
- 奇遇出現條件（事件 `minNature` / `maxNature`）

文字改法見 `EDITING.md`。

## 戰鬥

- **外功**＝可選招式；**內功**＝被動加成（不佔招式欄）。
- 招式特效（流血、破防、連擊、吸血、暈眩等）皆會改變戰局數值。

## 家庭

- 有紅顏／眷屬時，每月有很低機率得子。
- 一生孩子上限在開局隨機為 1–5 人，達上限後不再有生育事件。

## 劇本／事件

- 主線章節：`story/chapters.json`
- 隨機江湖包：`events/jianghu_random_events_100.json`（每選有 success／failure 解說）
- 日常／奇遇結果皆含 `narrate` 故事段，結果浮層先顯示解說，再列數值得失
- 編輯方式見根目錄 `EDITING.md`
