# 事件文案聲腔

## 聲腔定位

說書人在紙上落墨：克制、有氣味、有江湖氣。  
不寫成系統公告，不寫成網遊任務板。

## 句式

1. **一句一事**：雨先寫，人後寫；刀先聞，招後見。
2. **感官優先**：濕冷、茶溫、刀鳴、腳步泥濘、匾額金字剝落。
3. **留白**：結局給讀者補一筆；不要解釋情緒標籤（「他很傷心」→「酒杯見底，卻仍舉著」）。
4. **長度**：標題 ≤ 10 字；正文 40–90 字；選項 6–16 字。

## 標題（題簽）

像章回小標，不要問句堆疊。

| 好 | 差 |
|----|----|
| 夜雨投店 | 你要不要進去這家客棧？ |
| 橋上有人 | 隨機遭遇戰！ |
| 師門來信 | 系統郵件：門派通知 |

## 正文

```
秋雨未歇。你拍盡蓑衣上的泥，店小二卻只顧打量你腰間那柄無名劍。
屋內炭盆將旺未旺，有人在角落把酒杯磕得很輕——輕得像故意讓你聽見。
```

避免：`你獲得了 50 經驗`、`HP -10`、`任務進度 1/3`（效果另欄，不進正文）。

## 選項（批註）

寫成「我欲……／便……／且……」，像硃批，不像按鈕。

| 好 | 差 |
|----|----|
| 上前問一句來歷 | 對話 |
| 按下劍柄，不語 | 攻擊 |
| 付錢買一壺熱酒，坐遠些 | 休息回血 |
| 推門而出，雨更大了 | 離開（取消） |

每事件 2–4 選項；選項之間要有**性格差**（膽識／心機／慈悲／退卻），不要同義重複。

## 效果旁白（可選一句）

結算後可追加淡墨一句，像書吏補記：

- `從此腰間多了一枚無名玉佩。`
- `那年冬，師門名冊上多了你的字。`

## 忌諱

- 現代網路語、梗圖腔、中二大招全名堆疊
- 直接說數值（改由引擎 effect 處理）
- 道德說教結語（「所以做人要誠實」）
- 版權門派／角色名

## 屬性用詞（固定）

根骨 · 悟性 · 福緣 · 魅力 · 膽識  
氣血 · 銀兩 · 聲望 · 門派 · 年齡／歲
