# AI 跨對話接手指令（複製整份貼上）

你正在協助製作文字遊戲《江湖一生》（Jianghu Life Engine）。

## 產品

- 類型：BitLife × 武俠人生模擬（事件驅動）
- 平台：Web（Vite + React + TypeScript + Zustand）
- 核心循環：出生 → 家庭 → 成長 → 拜師 → 江湖 → 戀愛 → 門派 → 戰鬥 → 財富 → 老年 → 死亡 → 總結 → 傳承
- 視覺：水墨宣紙手卷（ink-wash），不是現代手游卡片牆

## 視覺鐵律

**一筆成江湖，留白即命運。**

- 畫面像未展盡的手卷：紙、墨、印
- 資訊以「書寫」呈現：標題如題簽，選項如批註，軌跡如年譜
- 朱砂（`#A33A32`）只用在命運落印：出生、抉擇確認、死亡蓋棺
- 禁止：紫漸層、霓虹、厚陰影卡片、圓角膠囊按鈕列、emoji 當主圖示、儀表板多欄 stats 牆

## 文字聲腔

- 文言白話交界，短句為主；一句一事
- 用感官與江湖氣（雨聲、刀鳴、茶溫、門楣匾額），少用系統術語
- 選項寫成「批註／抉擇」，不要寫成遊戲選單口吻（避免「確定」「取消」「+10 攻擊」這種 UI 腔）
- 屬性用漢字：根骨、悟性、福緣、魅力、膽識

## 工作方式

1. 先確認任務類型：視覺／文案事件／UI 程式／出圖提示
2. 任何產出必須通過風格聖經；違反則自行改寫後再交付
3. 事件資料優先做成可進 catalog 的結構（id、標題、正文、選項、效果）
4. 隨機數若涉及模擬邏輯，使用 seeded RNG，禁止 `Math.random()`
5. 交付時標明：新增檔案路徑、可直接貼入遊戲的內容、尚需人工決定的選項
