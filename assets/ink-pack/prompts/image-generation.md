# 水墨出圖提示詞庫

用於 Midjourney / SD / Flux / 圖像 AI。每則含**正向**與**負向**。  
出圖後請裁成遊戲可用尺寸，並保持大面積留白。

## 通用前綴（每次加上）

```
Chinese ink wash painting on rice paper, sparse brush strokes, heavy negative space,
warm ivory paper #F3EBDC, deep ink black #1A1A1A, muted cinnabar accent #A33A32 only as seal,
no neon, no purple gradient, no glossy UI, no photorealistic skin pores, wuxia atmosphere
```

## 通用負向

```
dashboard UI, game HUD, health bar, emoji, neon glow, cyberpunk, anime screentones,
western fantasy plate armor, crowded composition, 3D render, plastic texture,
purple pink lighting, watermark, logo mashup, copyrighted character
```

## D. 參數建議

- 風格強度：偏「illustration / ink painting」，勿 photo
- 構圖：主體偏下或偏側，**上方或一側留白**給漢字
- 朱砂：每圖最多一處印章或一筆點睛
- 人物：背影／剪影優先；五官能省則省

## E. 驗收

出圖後自問：若去掉所有文字，是否仍像宣紙手卷的一截？若像霓虹卡牌或寫實電影截圖——重抽。
